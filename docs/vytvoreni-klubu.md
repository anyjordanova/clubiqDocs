# Tvorba klubu

1. Na úvodní obrazovce klikněte na tlačítko **+** v pravém dolním rohu a zvolte možnost **"Vytvořit klub"**
2. Vyplňte základní informace:
   - Název klubu
   - Sportovní odvětví (hokej, fotbal, florbal)
   - Město a adresa
   - Logo klubu (volitelné)
3. Potvrďte vytvoření klubu

> TIP: Pro lepší identifikaci klubu doporučujeme nahrát logo.
