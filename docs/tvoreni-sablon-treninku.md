# Tvoření šablon tréninků

## Vytvoření nové šablony
- Trenér zadá název šablony.
- Vybere dovednosti pro jednotlivé pozice, které budou součástí šablony.

> Pro úspěšné vytvoření šablony je potřeba, aby alespoň jedna pozice měla přiřazené dovednosti.

## Výběr dovedností
- Dovednosti jsou vybírány z existujícího seznamu, který je spravován vlastníkem klubu.

## Uložení šablony
- Po výběru dovedností je šablona uložena a je k dispozici pro budoucí použití.
- Šablony lze kdykoliv upravit nebo odstranit.
